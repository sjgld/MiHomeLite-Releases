# MiHome Lite 发布渠道

此仓库公开 APK、版本说明和 SHA256 校验值。源码不在此仓库发布。

适配米家 11.8.703（110817031）和 Vector 2.2；这是测试模块，APK 使用 debug key 签名。

[下载最新发布](https://github.com/sjgld/MiHomeLite-Releases/releases)

安装后在 Vector 启用模块，作用域勾选米家，强制停止米家再打开。
设置入口：米家 → 我的 → 更多设置 → MiHome Lite 模块管理。

v0.10 起通过此公开渠道自动检查更新，无需 GitHub 账号或 Token。
打开米家时每 24 小时最多自动检查一次，可关闭或手动检查；结果在模块管理页显示，安装由用户操作。

此前版本的精简选择、桌面快捷方式开关和系统明暗模式继续保留。
本版不加入米家隐私数据拦截，不宣称已验证所有账号、地区和真实设备。
